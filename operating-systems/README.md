# Operating Systems

> Practical references for the operating systems engineers use every day — overviews, shells, terminal commands, and keyboard shortcuts. The focus is **macOS** and **Linux**; **Windows** is covered more lightly.

---

## Operating Systems

| OS | Description |
|---|---|
| [macOS](macos/README.md) | Apple's Unix-based desktop OS — Darwin/XNU, the zsh shell, macOS-specific commands, and ⌘ shortcuts |
| [Linux](linux/README.md) | The open-source, Unix-like OS behind servers and containers — distribution-agnostic kernel, shell, commands, and shortcuts |
| [Windows](windows/README.md) | Microsoft's NT-based OS — a lighter overview, its command environments (cmd/PowerShell/WSL), and shortcuts |
