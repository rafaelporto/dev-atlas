# SOLID

Five object-oriented design principles introduced by Robert C. Martin (Uncle Bob) that have, over time, become a vocabulary used across paradigms — OOP, functional programming, and dynamically typed languages alike.

The principles are not a checklist. They are a lens for spotting designs that will become painful to change, and a vocabulary for talking about *why* one structure is better than another.
