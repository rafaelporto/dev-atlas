# Message Brokers

Deep dives into the most widely used message brokers — market-standard self-hosted platforms and fully managed cloud services. Each article covers what the broker solves, its advantages and disadvantages, and when NOT to use it. For a side-by-side view and a decision guide, see the [Broker Comparison](../comparison.md).

| [Google Cloud Pub/Sub](google-pubsub.md) | Managed, globally scalable publish/subscribe messaging on GCP |
