# Pragmatic Principles

Four heuristics — older than [SOLID](../solid/README.md), shorter to state, and applicable to any language or paradigm — that capture the day-to-day discipline of writing code that survives contact with change.

They are easy to learn, hard to apply well, and they pull against each other often enough that the *interaction* between them deserves its own article.
